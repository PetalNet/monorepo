# Hey Janet design

Inherits the lab's Material 3 / DaisyUI visual language. This is an Operate surface used on a phone in ordinary room light, with an automatic dark theme for dim rooms.

A single recording station anchors the flow: generous phrase typography, delivery direction, a live horizontal level meter, then the primary action. A persistent top rail identifies the booth; the footer names local and uploaded status. The curation surface uses the same controls in a denser list.

Restrained color: cool white / charcoal surfaces and a deep plum accent. Light text pairs: ink #202027, secondary #494650, primary #58254f on #f6f5f7 or #ffffff. Dark pairs: ink #f5f2f6, secondary #c9c3cc, primary #edc4e4 on #18161b or #242127. Accent buttons invert their text to the corresponding base. Measure all pairs in browser verification.

8px spacing grid, 2px corners, borderless filled surfaces, hairline separators. Default tracking. Geist when available locally, system sans fallback. Controls have 48px minimum height and a visible focus outline. Lucide icons accompany text, never replace essential labels. Motion is brief and respects reduced motion. No external image or inference calls.
