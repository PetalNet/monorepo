# Grove

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and Purpose

Lab operators create projects, inspect ready work, independently review Agent outputs, and retrieve accepted artifacts with stable provenance.

## Capabilities and Constraints

Browser, REST, and MCP operations share Grove's actor-authorized command plane. Projects and artifacts have immutable Versions. Task completion requires an independently accepted output and an expected Task Version. Execution Agents enroll separately from browser Persons.

The console opens projects by ID. Project listing, submitted-output discovery, and an automatic review inbox require read contracts that are not exposed by the project API. Reviews use publication-receipt references; reviewers examine the output supplied by its author outside this console before submitting a decision.

## Brand Commitments

The `console-legacy` reference supplies the compact operational shell, paper/ink surfaces, restrained sienna accent, and evidence-first language. Unsupported fleet, assistant, cost, and telemetry controls are absent.

## Accessibility

Target AAA text contrast in light and dark modes, semantic controls, visible keyboard focus, reduced motion, and responsive layouts.
